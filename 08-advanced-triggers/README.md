# 08 — Advanced Triggers

## Learning Objectives
- Handle non-basic automation events safely.
- Build reliable debug patterns for complex triggers.

## Concepts
- `workflow_run`, `repository_dispatch`, `issue_comment`.
- Concurrency control and cancellation rules.
- Conditional execution with advanced expressions.

## Practical Exercises
- Draft advanced trigger workflows in `workflows/`.
- Keep event examples in `examples/`.
- Store debug playbooks in `docs/`.

## Interview + Troubleshooting
- When should `workflow_run` be used?
- How do you prevent duplicate runs?
- Debug unexpected condition evaluation.

## Completion Checklist
- [ ] I implemented at least 2 advanced triggers.
- [ ] I added concurrency safeguards.
- [ ] I documented a trigger-debug checklist.
