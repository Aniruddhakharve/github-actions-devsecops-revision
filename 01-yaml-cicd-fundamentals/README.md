# 01 — YAML + CI/CD Fundamentals

## Learning Objectives
- Understand YAML syntax used in workflow files.
- Map CI/CD stages to GitHub Actions workflow structure.

## Concepts
- Keys, lists, anchors, indentation, quoting.
- Workflow anatomy: `name`, `on`, `jobs`, `steps`.
- Basic pipeline flow: checkout → build/test → report.

## Practical Exercises
- Create sample YAML snippets in `examples/`.
- Draft a minimal workflow in `workflows/`.
- Document YAML mistakes and fixes in `docs/`.

## Interview + Troubleshooting
- Explain why indentation errors break workflows.
- Compare CI vs CD with practical examples.
- Debug a failing workflow caused by invalid YAML.

## Completion Checklist
- [ ] I can write valid workflow YAML without syntax errors.
- [ ] I can explain each top-level workflow key.
- [ ] I captured at least 3 common YAML pitfalls.
